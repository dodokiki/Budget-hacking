# ตามรอยงบประมาณ 2570

สารคดีข้อมูล (scrollytelling) เล่า 6 เรื่องที่พบจากการอ่านเอกสารงบประมาณของรัฐไทย 318 ไฟล์

หน้าเว็บเป็นไฟล์เดียวจบ ไม่มี dependency ไม่มี build step — `index.html` เปิดได้เลย

## เนื้อหา 6 บท

| บท | เรื่อง | ตัวเลขหลัก |
|---|---|---|
| 1 | เงินถึงมือคนไม่เท่ากัน | อบจ. สมุทรปราการ 3,100 ลบ. vs เชียงใหม่ 2,761 ลบ. · อบต. ราชาเทวะ 615 ลบ. = 31% ของเทศบาลนครเชียงใหม่ |
| 2 | บัญชีที่ตรวจไม่ได้ | สตง. "ไม่แสดงความเห็น" ต่องบการเงิน สปส. 2568 — คลาดเคลื่อน 382.7 ลบ. และ 3,600 ลบ. |
| 3 | คลินิกที่โตเร็วเกินไป | งบคลินิกนวัตกรรม 2,062 → 6,782 → 4,178 ลบ. · ยอดใช้บริการร่วง 614,330 → 268,123 ครั้ง/สัปดาห์ |
| 4 | เงินที่นอนหลับ | กองทุนอนุรักษ์พลังงาน: เงินสดคงเหลือหลักหมื่นล้านทุกปี ขณะที่ใช้จริงลดเหลือ 198 ลบ. (2568) |
| 5 | ราคากลางที่ "บังเอิญ" ตรงเป๊ะ | โครงการสื่อดิจิทัล ศธ. — ราคาผู้ชนะ 195.6 ลบ. ตรงกับราคากลางพอดี (คู่แข่ง 198.0 / 204.0) |
| 6 | ก้อนเงินที่ใหญ่กว่าทุกกระทรวง | งบกลางแซงทุกกระทรวงในปี 2563 · 375,708 → 842,002 ลบ. · ส่วนแบ่ง 14.6% → 22.4% |

## แหล่งข้อมูล

- **PBO** (สำนักงบประมาณของรัฐสภา) — ข้อมูลงบประมาณรายจ่ายเปรียบเทียบ ปีงบประมาณ 2558–2568
- **กมธ.ติดตามงบประมาณ ปี 2569** — เอกสารชี้แจงจากการประชุม 13 ครั้ง 28 หน่วยงาน
- **ร่าง พ.ร.บ. งบประมาณ 2570** — 96,470 รายการ รวม 3.79 ล้านล้านบาท
- **งบท้องถิ่น** — ข้อบัญญัติงบประมาณ 2570 ของเชียงใหม่และสมุทรปราการ

เอกสารต้นฉบับ (~3.2 GB) ไม่ได้อยู่ใน repo นี้ — ดู `.gitignore`

## ข้อจำกัดของข้อมูล ที่ระบุไว้บนหน้าเว็บด้วย

- **ปีงบประมาณ 2562 รายกระทรวงเสียหายในไฟล์ต้นฉบับ** (สำนักนายกฯ อ่านได้เป็น 607 ล้านล้านบาท, คลัง/กลาโหมเป็น 0) จึงข้ามปีนั้นในกราฟแข่งขัน และแสดงข้อความบอกผู้ชมตอนวิ่งผ่าน ไม่ได้เติมตัวเลขแทน
- **ยอดนำส่งคลังของกองทุนอนุรักษ์พลังงานปี 2568** (2,246 ลบ.) ยังอยู่ระหว่างเสนอ ครม. ยังไม่ได้จ่ายจริง
- **ตัวเลขประชากรรายจังหวัด** ที่ใช้คำนวณงบต่อหัว เป็นข้อมูลภายนอก ไม่ได้อยู่ในชุดเอกสารนี้
- ตัวเลขงบประมาณรายปีจาก PBO **รวม พ.ร.บ. งบประมาณเพิ่มเติม** แล้ว (เช่น 2560 = 2.733 ล้านล้าน + เพิ่มเติม 190,000 ลบ. = 2.923 ล้านล้าน)
- การเทียบ อบต. ราชาเทวะ ใช้ **งบรวมเทียบงบรวม** กับเทศบาลนครเชียงใหม่ ไม่ใช่เทียบกับเงินอุดหนุนเฉลี่ย ซึ่งเป็นคนละฐาน

## การใช้งาน

เปิดไฟล์ `index.html` ตรงๆ หรือเสิร์ฟผ่าน static server ใดก็ได้:

```bash
python -m http.server 5173
```

**Deploy บน Vercel:** import repo นี้ แล้วเลือก framework preset เป็น *Other* — ไม่ต้องตั้ง build command หรือ output directory

## การควบคุม

- **เลื่อน (scroll)** เพื่อคุมจังหวะเอง — แต่ละฉากหยุดให้ดูได้นานเท่าที่ต้องการ
- **ปุ่ม "เล่นอัตโนมัติ"** มุมขวาบน ให้เล่นเองทั้งเรื่อง (แตะหรือหมุนเมาส์เพื่อหยุด)
- **ลูกศร / เว้นวรรค** สำหรับคีย์บอร์ด
- รองรับ `prefers-reduced-motion` — ปิดการเคลื่อนไหวทั้งหมดให้ผู้ที่ตั้งค่าไว้
